# 架构与评审

精确整数乘积先于舍入、溢出检测和钳位。参数化单文件提供 NATIVE 基线；生成器负责 BINARY/CSD/有界加减图和 DAG 分级。输出为位向量，类型进入接口清单。FULL 自动位宽用端点区间推导；源文档中的 OUTPUT_WIDTH/OUTPUT_SIGNED 仅在 QUANTIZED 配置时生效。

系数以十进制字符串输入，拒绝浮点；SV 以 129 位有符号参数接收并检查 1–128 位承载范围。生成器省略 COEFF_WIDTH 时取最小承载宽度；机器参数空间默认 128，以容纳宽系数测试。

NATIVE 可用输出寄存器满足延迟，不宣称算术切分。生成图按深度分级，跨级边显式插入配平寄存器；最后一级执行量化。所有寄存器使用同一 ce，复位优先且仅清 valid，无效数据无保证。输入隔离仅改变无效样本。

设计评审：signed 扩展在移位及加减前完成；量化采用 floor 商与非负余数实现对称 ties-to-even；中间数据宽度保守保留，不做未证明裁剪。AUTO 无可信工艺缓存回退 NATIVE。时钟仅使用 clk_i。用户已有实现授权，完成上述评审后继续。

DAG 的量化前节点 coefficient 表示精确的 X 倍数。quantize 及其最终输出寄存器的 coefficient 记录所关联精确乘积的系数，输出数值语义由规范化量化配置决定，不声称舍入/饱和后的输出仍是 X 的线性整数倍。中间节点统一使用足够宽的有符号承载，无符号输入先零扩展。
