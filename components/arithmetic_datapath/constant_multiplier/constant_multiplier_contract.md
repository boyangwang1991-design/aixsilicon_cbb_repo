# AIXSILICON Constant Multiplier CBB 需求规格

本文规定编译期常数乘法 CBB 的功能、数值语义、时序合同、生成能力、验证与 PPA 寻优要求，可作为架构设计和 RTL 实现输入。本文为规划草案，不代表已有实现或通过验证；登记编号沿用仓库分配机制，不在本文件中另行创造。

## 1. 定位与范围

本 CBB 完成单个输入与编译期固定整数系数的乘法，以及可选的输出量化：`y = Q(C × x)`。它属于可复用、与 PPA 强相关的算术核心，不包含 APB/AXI、配置寄存器、DMA、任务队列或中断。

支持参数化 RTL 和脚本生成的专用结构两种交付方式；Generator 不改变 CBB 分类。主要目标为 ASIC，FPGA 映射可以作为独立平台目标，不能混用两者的 PPA 结论。

| 能力 | V1.0 要求 |
|---|---|
| 单输入、单固定系数 | 必须 |
| 无符号/二补码有符号输入，正/负/零系数 | 必须 |
| 全精度输出 | 必须，默认模式 |
| 右移量化、舍入、溢出检测、可选饱和 | 必须支持，通过静态配置裁剪 |
| 组合模式、固定延迟流水线模式 | 必须 |
| 原生乘法表达式实现 | 必须，作为基线和回退 |
| 二进制展开、CSD、加减法图候选生成 | 必须；图搜索不要求证明全局最优 |
| 系数分析、等价检查及 PPA 实验脚本 | 必须 |
| 压缩树候选 | PPA 探索项，有收益再产品化 |
| 多常数共享 MCM | 后续扩展，本版本不增加多输出接口 |
| 运行期可编程系数、时分复用串行乘法、浮点、近似计算 | 不在 V1.0 范围 |

规范中“必须”为验收项，“建议”为架构提示，“探索项”不作为 V1.0 功能阻断项。所有候选必须实现相同数值合同；不得用近似计算换取未声明的收益。

## 2. 参数与数值合同

### 2.1 静态配置

以下为逻辑配置字段，具体 SV 参数映射可在接口冻结时调整，但不能改变语义。

| 字段 | 含义与约束 | 建议默认值 |
|---|---|---|
| INPUT_WIDTH | 输入位宽，V1.0 验收范围 1～128 | 16 |
| INPUT_SIGNED | 输入按无符号或二补码解释 | true |
| COEFF | 精确整数常数，禁止经过浮点解析 | 3 |
| COEFF_WIDTH | 系数二补码承载位宽，1～128；必须能表示 COEFF | 由脚本推导 |
| OUTPUT_MODE | FULL / QUANTIZED | FULL |
| OUTPUT_SIGNED | FULL 自动推导；QUANTIZED 显式指定 | 自动 |
| OUTPUT_WIDTH | FULL 自动推导；QUANTIZED 为 1～256 | 自动 |
| SHIFT_RIGHT | 量化右移位数，0～256 | 0 |
| ROUND_MODE | FLOOR / TOWARD_ZERO / NEAREST_EVEN | FLOOR |
| OVERFLOW_MODE | WRAP / SATURATE | WRAP |
| LATENCY | 组合模式为 0，流水模式为 1～8 | 0 |
| IMPL | NATIVE / BINARY / CSD / ADDER_GRAPH / AUTO | NATIVE |
| OPERAND_ISOLATION | 是否屏蔽无效输入的数据翻转 | false |

上述范围是本规格提出的实现和验收目标，不代表任意组合均可达到某一频率。功能合法但达不到时序目标应报告“时序未达标”，不能与非法配置混为一谈。超出范围必须明确拒绝，或作为单独验证过的扩展发布。

`COEFF` 在 YAML 中建议用十进制字符串保存；Python 使用任意精度整数，SV 后端输出带明确宽度和符号的常量，禁止依赖 32 位 `int` 保存大系数。正系数的二补码承载必须保留符号位。

### 2.2 精确乘积与全精度宽度

**CM-NUM-001**：先按输入类型解释整数 X，再计算数学整数 `P = C × X`。所有实现必须对全部合法输入保持该定义。

输入范围：无符号为 `[0, 2^W−1]`；有符号为 `[−2^(W−1), 2^(W−1)−1]`。令 `Pmin=min(C×Xmin,C×Xmax)`，`Pmax=max(C×Xmin,C×Xmax)`。

**CM-NUM-002**：FULL 模式输出类型在 `INPUT_SIGNED=true` 或 `C<0` 时为有符号，否则为无符号。宽度取能够表示 `[Pmin,Pmax]` 的最小正整数 B：

- 有符号：`−2^(B−1) ≤ Pmin` 且 `Pmax ≤ 2^(B−1)−1`。
- 无符号：`0 ≤ Pmin` 且 `Pmax ≤ 2^B−1`。
- 零系数至少保留 1 位输出。

例如 8 位有符号输入乘以 −1，输出需要 9 位，因为输入 −128 对应输出 +128。不能仅根据系数绝对值或输出连接宽度猜测结果位宽。

**CM-NUM-003**：FULL 必须要求 SHIFT_RIGHT=0，禁止配置量化舍入或饱和来改变结果；不相容配置应报错。FULL 模式 overflow_o 恒为 0。

**CM-NUM-004**：中间节点必须使用能够保持精确结果的位宽，或具有经过证明的等价裁剪。执行左移、加减和取负前应完成必要扩位，显式处理有无符号转换。不能先在窄位宽中溢出，再扩宽结果。

### 2.3 量化、舍入与溢出

**CM-NUM-005**：QUANTIZED 模式按固定顺序处理：精确乘积 P → 除以 `2^SHIFT_RIGHT` 并舍入得到整数 R → 检查输出可表示范围 → WRAP 或 SATURATE。

| 舍入方式 | 精确定义 | 示例，P=−7，SHIFT_RIGHT=1 |
|---|---|---|
| FLOOR | 向负无穷取整 | −4 |
| TOWARD_ZERO | 向零取整 | −3 |
| NEAREST_EVEN | 最近整数；恰好半整数时取偶数 | −4 |

**CM-NUM-006**：NEAREST_EVEN 必须对正负数对称正确，包含 guard/sticky 信息，不能统一加一个正偏置代替所有舍入语义。SHIFT_RIGHT=0 时舍入不改变 P。

**CM-NUM-007**：`overflow_o=1` 当且仅当 R 超出输出类型及 OUTPUT_WIDTH 的表示范围。丢弃小数位本身不是溢出。

- WRAP：输出 R 模 `2^OUTPUT_WIDTH` 的位向量，再按 OUTPUT_SIGNED 解释。
- SATURATE：将 R 钳位到输出类型的上下限；无符号输出的负数钳位为 0。
- 溢出状态必须与对应数据和 valid 对齐，在两种模式下均反映钳位/回绕前是否越界。

**CM-NUM-008**：定点乘法可由整数系数与 SHIFT_RIGHT 表达，系数量化误差由上层负责；本 CBB 不从实数自动猜测缩放关系。若输入有 Fx 个小数位、系数整数编码对应 Fc 个小数位，则输出缩放为 Fx+Fc−SHIFT_RIGHT，由集成方记录。

## 3. 接口与周期行为

| 信号 | 方向 | 语义 |
|---|---|---|
| clk_i | 输入 | 单时钟，LATENCY>0 时使用 |
| rst_ni | 输入 | 低有效同步复位，LATENCY>0 时使用 |
| ce_i | 输入 | 全流水线时钟使能，LATENCY>0 时使用 |
| valid_i | 输入 | 输入样本有效 |
| data_i | 输入 | INPUT_WIDTH 位输入数据 |
| valid_o | 输出 | 输出样本有效 |
| data_o | 输出 | 规定输出宽度及类型的数据 |
| overflow_o | 输出 | 与结果对齐的溢出标志 |

**CM-IF-001**：LATENCY=0 为纯组合逻辑，`valid_o=valid_i`；clk_i、rst_ni、ce_i 不影响组合语义，无锁存器和隐式状态。

**CM-IF-002**：LATENCY=L>0 时，rst_ni=1 且 ce_i=1 的上升沿为推进边沿。以 n 编号推进边沿，令输入 I[n] 为边沿前的样本，输出 O[n] 为边沿后的值，则 `O[n]=F(I[n−L+1])`，有效位同样延迟。L=1 表示在接收输入的当前边沿后输出结果；L=2 在下一个推进边沿后输出。复位填充的空位无效。

**CM-IF-003**：ce_i=0 时数据、valid 和 overflow 的所有流水状态保持，不接收新输入；valid_o 也保持，接收方不得把保持的结果当成新的重复传输。有效传输以推进边沿为准，本接口没有独立 ready/背压功能。

**CM-IF-004**：ce_i=1 且 valid_i=0 时推进一个空泡；不能因 valid_i=0 停止全流水线，导致已有有效样本无法排出。持续有效且 ce_i=1 时启动间隔 II=1。

**CM-IF-005**：复位优先于 ce_i。复位采样边沿后所有 valid 状态清零，丢弃在途样本。数据寄存器允许不复位以降低面积和复位扇出；valid_o=0 时 data_o、overflow_o 不构成功能保证。复位释放后的输出只能对应新接收的数据。

**CM-IF-006**：LATENCY 为对外固定合同；不同结构须通过分级及必要的延迟配平保持合同。串接输出寄存器满足延迟合同，但不能声称因此完成算术路径切分或提升最高频率。

## 4. 基本功能要求

| ID | 要求 |
|---|---|
| CM-FUN-001 | 支持 C=0、±1、±2^k、2^k±1、稀疏、稠密及一般系数 |
| CM-FUN-002 | 系数必须是 elaboration/生成期常数，不存在运行期系数端口 |
| CM-FUN-003 | 特殊常数应允许综合消除不必要算术逻辑，但不能改变时序接口 |
| CM-FUN-004 | 所有实现模式在相同配置下数值、有效位、使能、复位和溢出行为一致 |
| CM-FUN-005 | 输出类型、最终位宽、实际延迟及结构选择必须可查询并进入生成清单 |
| CM-FUN-006 | 无效输入允许操作数隔离；不得影响在途有效计算或改变 valid 行为 |
| CM-FUN-007 | 不生成派生时钟，不在 RTL 内以组合逻辑直接门控 clk_i；使用同步使能，ICG 映射交给受约束流程 |

## 5. 实现与生成器要求

### 5.1 综合器与生成器分工

**CM-IMP-001**：NATIVE 使用显式宽度/符号的乘法表达式作为必须保留的基线。允许综合器完成常量传播、算术重构、位宽裁剪、逻辑化简、单元选择与时序优化。

**CM-IMP-002**：生成器负责候选拓扑、公共中间计算、节点精度、流水线切分及配平；默认不施加 dont_touch。若不同候选被综合为同一结构，应如实记录，不人为阻止正常优化来制造差异。

**CM-IMP-003**：手工结构不具有默认优先权；以目标工艺和约束下的结果选择。综合器不能被假定会自动满足指定多级流水线分割，任何重定时必须有配置和等价验证证据。

### 5.2 最小算术图

脚本采用“规范化配置 → 算术 DAG → 位宽分析 → 结构/分级选择 → SV 输出”的流程。无需引入完整通用硬件编译器，但不能仅拼接字符串而缺少可校验的中间表示。

**CM-GEN-001**：DAG 至少表达 input、constant、固定 shift、add、sub、register、量化输出；每个节点记录唯一 ID、输入边、结果相对于 X 的整数系数、位宽、符号、所在流水级。组合部分必须无环。

**CM-GEN-002**：生成前校验图的计算系数、位宽、无环性、寄存器级号和分支对齐。共享节点跨流水级使用时必须配平；不能混用不同输入样本。

**CM-GEN-003**：支持确定性的 BINARY 和 CSD 生成，以及有预算上限的 ADDER_GRAPH 搜索。图搜索可使用启发式，不得宣称全局最优；记录算法版本、搜索预算和随机种子。

**CM-GEN-004**：输出规范化配置、RTL、图结构、接口/位宽清单、FuseSoC 描述或集成片段、验证入口和 PPA 结果索引。重复输入及工具版本应生成可复现结果。

**CM-GEN-005**：AUTO 有目标工艺 PPA 缓存时可选择满足约束的候选；仅有静态估算时必须标记为 estimated。无法获得可信选择时回退 NATIVE 并记录原因，不得声称已完成 PPA 寻优。

**CM-GEN-006**：非法参数、系数越界、图错误、无法实现指定精确数值合同必须报错；搜索超时允许保留已验证候选或回退。不能无提示修改系数、延迟或精度。

## 6. 附录 A：需要进行 PPA 寻优的结构

以下结构是实验候选及比较方法，不预先承诺收益。候选可以组合，例如 CSD 加平衡树再进行流水分级。

### A1. 原生乘法与特殊常数化简

- 结构：`P = X × C`，由综合器优化；显式特殊路径可表达零、直通、取负和固定移位。
- 样例：C=0、1、−1、16、−16。
- 比较点：综合器是否已实现同等化简；特殊分支是否真正减少面积或改善路径。
- 约束：固定移位不需要通用移位器，但布线、负载和缓冲仍有物理成本。取负需要正确扩位，不能一概视作零成本。

### A2. 二进制部分积：串联链与平衡树

以 85X 为例：`X + (X<<2) + (X<<4) + (X<<6)`。

- 链式：逐项相加，形成三个依赖加法节点。
- 平衡树：`a=X+(X<<2)`，`b=(X<<4)+(X<<6)`，`P=a+b`，形成两层依赖。
- 寻优变量：求和顺序、树形、每个节点宽度、分支对齐、输入扇出。
- 主要目标：在面积和路径深度间取舍；“两层”只是运算图层数，不等于门级延迟固定减为 2/3。

### A3. CSD/带符号数字展开

样例：`31X=(X<<5)−X`，`63X=(X<<6)−X`。

- 将连续非零二进制位转换为较少的加减项，并比较链式与平衡式归并。
- 寻优变量：表示形式、加减归并顺序、补码处理、节点宽度、流水位置。
- 比较基线：NATIVE、BINARY；对于稀疏系数和稠密系数分别统计。
- 注意：CSD 减少表示中的非零数字，不保证一般加减法图的运算数最少，更不保证布局布线后的 PPA 最优。

### A4. 因式分解及加减法图复用

以 45X 为例：`t=(X<<2)+X`，`P=(t<<3)+t`，即先算 5X 再乘 9。

- 与二进制展开及 CSD 展开比较，观察两次相依加法是否具有收益。
- 寻优变量：因式分解、加减链、公共节点、节点扩位、最大路径深度。
- 成本函数至少考虑加减节点位宽、逻辑深度、扇出和寄存器数量，不能只计算加法器个数。
- 允许为缩短路径复制部分计算；最少节点与最高频率可能选择不同结构。

### A5. 多操作数压缩树与最终进位传播

- 适用于展开后项数较多、宽度较大的候选：先用 carry-save/3:2 压缩减少操作数，再做最终进位传播加法。
- 比较对象：普通 `+` 归并树、综合器从 NATIVE 推导的实现。
- 寻优变量：压缩顺序、树形、最终加法器映射、符号扩展、负项修正、分级位置。
- 固定常数导致的部分积稀疏可能削弱显式压缩树收益；负项不能被当成普通无符号部分积直接相加。
- 本项为探索，不要求为小系数强制生成压缩树，也不要求强制实例化门级全加器。

### A6. 流水线切分与分支延迟配平

- 在相同 LATENCY 下比较：输出堆叠寄存器、按图深度切分、按估计延迟切分、结合节点位宽切分。
- 寻优变量：每级算术深度、级边界、跨级信号宽度、配平寄存器、共享或复制节点。
- 除数据路径外，必须包含量化舍入和饱和路径，不能让输出处理成为未计入的瓶颈。
- 比较总面积、最差级延迟、触发器数、时钟功耗和布线。允许另绘不同延迟的 Pareto 结果，但不能将不同延迟直接声称为同条件收益。

### A7. 精度裁剪与输出量化融合

- 比较“完整乘积再量化”和“经证明等价的精度感知计算”。
- 仅取低位且 WRAP 时可探索模算术；输出高位、右移舍入、溢出检测或饱和时，必须保留相关进位、符号和 sticky 信息。
- 寻优变量：节点宽度、可删除位、舍入增量合并、溢出/饱和判定复用。
- 所有裁剪均须对最终 data_o 和 overflow_o 证明等价。不能简单删除被右移掉的低位部分积，因为它们可能向保留位进位。

### A8. 无效周期操作数隔离

- 比较隔离关闭、输入端隔离，以及经过验证的局部无效级隔离。
- 对连续满负载、10%/50% 有效占空比和突发流量分别测量。
- 寻优变量：隔离位置、MUX 成本、valid 扇出和数据相关性。
- 无效样本可以钳零；有效样本与在途状态不能破坏。功耗实验必须计入隔离控制和时钟树开销。

### A9. 后续扩展：多常数共享 MCM

示例同一输入产生 45X 和 75X：`t=5X`，`y0=(t<<3)+t`，`y1=(t<<4)−t`。

- 比较多个独立 constant_multiplier 与联合图共享。
- 寻优变量：共享/复制、中间值扇出、输出流水配平与布线距离。
- 只允许共享同一个输入样本对应的计算；不同独立输入流不属于该优化。
- 作为独立多输出扩展设计，不将本项混入 V1.0 单输出验收。

## 7. 附录 B：PPA 实验与选型合同

### 7.1 实验矩阵

| 维度 | 必测或代表性样本 |
|---|---|
| 输入位宽 | 1、8、16、32、64、128；边界验证另包含 2 位 |
| 系数 | 0、±1、±2^k、2^k±1、45、85、341、交替位型、固定种子的随机正负系数 |
| 系数位宽边界 | 1 位合法值、最大正数、最小负数、128 位边界；按配置过滤非法值 |
| 类型 | 有符号/无符号输入，全精度；有符号/无符号量化输出 |
| 延迟 | 0、1、2、3、4；8 用于支持上限验收 |
| 量化 | 不右移、一般右移、右移超过乘积宽度；三种舍入及两种溢出处理 |
| 结构 | NATIVE、BINARY、CSD、ADDER_GRAPH；压缩树为探索 |
| 流量 | 连续有效、空泡、突发、ce 暂停；数据含随机、缓变和高翻转模式 |

不要求全部维度笛卡尔积跑布局布线。先综合筛选代表性组合，再对有竞争力的候选进行物理实现；必须覆盖每类结构、典型系数和极端位宽，不能只挑选有利系数。

### 7.2 公平比较条件

**CM-PPA-001**：同组比较必须固定目标库、PVT、工具及版本、综合策略、输入输出约束、负载、输出精度、LATENCY、II、复位/使能语义。组合模式使用虚拟时钟或等效 I/O 延迟预算。

**CM-PPA-002**：结果记录标准单元面积、组合/时序面积、最差路径延迟、WNS/TNS、触发器数、buffer 数、最大扇出；物理实现补充布线和拥塞信息。工具无法获得的指标标记 unavailable，不能填 0。

**CM-PPA-003**：功耗分开报告动态和漏电，记录电压、频率、活动来源和仿真窗口。声称毛刺功耗收益时需要能反映门级延迟的活动证据；仅 RTL 活动估算不能证明该项收益。报告每有效样本能量，并说明无有效样本时该指标不适用。

**CM-PPA-004**：默认面积模式为“满足规定延迟及约束后面积最小”；时序模式为“满足面积上限后路径最短”；功耗模式为“满足面积/时序及流量条件后功耗或能量最小”。未配置数值上限时返回 Pareto 候选，不暗设加权分数冒充唯一最优。

**CM-PPA-005**：每项结果标记 estimated / synthesized / placed / routed。综合面积和时序用于筛选，最终芯片实现选型优先使用相同物理流程的结果。未跑实际流程不得填写 PPA 改善百分比。

**CM-PPA-006**：NATIVE 与其他结构在相同条件下比较；若生成结构无收益，选择 NATIVE 即为合法结论。V1.0 验收不要求任意系数都优于综合器，也不预设统一 10% 或 20% 改善门槛。

结果建议包含：配置哈希、RTL 哈希、系数、位宽、类型、输出语义、延迟、结构、图搜索信息、工具/库/PVT、约束、面积、延迟、功耗、结果成熟度、等价验证状态和选择理由。

## 8. 验证与验收

| ID | 验证要求 |
|---|---|
| CM-VER-001 | 建立独立任意精度整数参考模型，按本文件顺序实现舍入和溢出，不复用生成器 DAG 计算结果作为唯一 oracle |
| CM-VER-002 | 小位宽穷举全部输入，覆盖正负/零系数；大位宽覆盖上下限、0、±1、符号边界和随机样本 |
| CM-VER-003 | 覆盖负数最小值取负、负系数、无符号输入乘负系数及宽系数，不允许宿主语言整数截断 |
| CM-VER-004 | 覆盖正负半值舍入、偶数/奇数 tie、饱和上下边界、刚好越界、超大右移和 SHIFT_RIGHT=0 |
| CM-VER-005 | 验证连续输入、空泡、ce 暂停、复位期间 ce=0、运行中复位、复位后重新填充及无重复/丢失有效样本 |
| CM-VER-006 | 对发布的结构/参数回归集合做组合或时序等价检查，涵盖数据、valid 和 overflow；形式工具不可用时明确记录证据缺口，不得声称已完成形式证明 |
| CM-VER-007 | 无意外 latch、组合环、未驱动有效信号、符号/位宽高风险告警；不以批量忽略告警代替修复 |
| CM-VER-008 | 生成器检查非法配置、搜索超时/回退、重复运行一致性、图级对齐错误；生成示例可以通过 FuseSoC 调用 |
| CM-VER-009 | 在 ce 持续有效时 II=1，LATENCY=0～8 的已发布实现遵守周期公式；特殊系数不能绕过规定延迟 |
| CM-VER-010 | 至少形成一组固定 ASIC 库/约束下的完整 PPA 对比，并包含 NATIVE、BINARY、CSD、ADDER_GRAPH；若环境尚不可用，PPA 验收保持未完成 |

全参数空间不以有限仿真宣称穷尽验证。发布时明确参数支持范围、回归矩阵及形式检查范围；实际生成实例应有可重复的验证入口，未经检查的实例不自动继承“已证明”状态。

## 9. 交付物与冻结事项

必须交付：需求规格、接口与架构说明、规范化 YAML 配置规则、参数化 RTL、结构生成脚本、DAG/位宽清单、独立参考模型、验证用例与结果、FuseSoC 集成入口、PPA 执行脚本与报告模板、代表性实验报告和使用指南。

接口冻结时必须落实：SV 参数承载方式、输出自动推导实现、复位/ce 周期合同、配置非法组合检查、各后端的流水线分级能力、目标工艺库及 PPA 约束。没有工艺输入不阻碍功能 RTL 开发，但不能据此冻结“最优实现”。

实施顺序建议：先实现数值合同与 NATIVE；再实现确定性的 BINARY/CSD 和等价回归；随后加入有界 ADDER_GRAPH 搜索及流水切分；最终以同条件 PPA 结果决定默认候选。压缩树和 MCM 依据应用收益推进。
