# 静态检查说明与限定豁免

基线：DC `run-20260910-133744-259546`、`run-20260910-134152-503471`；VCS 最终回归见 reports/verification-result.json。
本表为实现审查中的限定解释，不构成组织级物理签核豁免。

| 诊断 | 适用条件 | 解释与验收 |
|---|---|---|
| LINT-28 | 参数关闭路径、非共享通道、D=P=0 | 未使用的端口被常量裁剪；无未驱动的有效比较数据 |
| LINT-29 | D=0 或 Level 1 共享数据 | 合约要求的旁路/共享输入直通 |
| LINT-31 | 最终汇总 | `OR(A,B) OR XOR(A,B)` 化简为 `OR(A,B)`，两个公开输出同值合法 |
| LINT-33 | 不使用的共享端口 | 多位端口同接常量零，未构成多驱动 |
| LINT-52 | R=0 或 STATIC_COMPARE_MASK=0 | 内部故障恒零或全部差异输出恒零，符合关闭配置 |
| LINT-2、LINT-8 | 仅 STATIC_COMPARE_MASK=0 | 比较逻辑裁剪后的未负载诊断连接/输入；其他配置不接受此豁免 |

PPA 提取器拒绝表外诊断；所有正式功能配置经过 RTL 仿真。综合网表还由 Formality 检查等价。
本次未进行独立 SpyGlass 安全规则签核；VCS lint 与 DC check_design 是本轮静态基线。
