# 冗余实现详细设计

参数、端口遵循源合约，行为和同拍事件优先级固定于 behavior.yaml 与实现规格。
本轮详设评审依据用户实现授权完成；规格严格检查通过后才进入 RTL。

## 数据与状态

路径索引 0=A、1=B，Level 0 不生成 B。每个独立路径内部声明自己的 delay array 和启动计数；
Level 1 的 B 只引用 A 的延迟/启动输出。注入选择分别译码。
延迟注入作用于第零级输入；比较注入作用于对齐操作数，随后依次经过 XOR、mask、归约。
延迟始终移动，比较禁用不能破坏时间关系。

启动计数在 D+G 饱和，求和采用 64 位扩展防止 unsigned 加法溢出。
D=G=0 不生成计数器；D=0 不声明空数组。P=1 分别寄存两路差异向量。
复位立即屏蔽结果，所有状态清零。Sticky 捕获沿前实时结果，清除与故障同时发生时故障优先。

## 断言与验证

安全输出汇总、复位屏蔽、有效操作数 X/Z 检查具有稳定 PROP ID。
测试台在输入稳定后检查沿前结果，再更新参考状态并检查沿后结果，避免采样错位。
故障注入通过真实数据路径传播；另用单路 stuck-at-0 检查 fail-safe OR 行为。

## PPA 优化点

XOR、mask、归约路径的逻辑深度为 O(log2(W))，每路比较面积 O(W)。
延迟面积随 D×W×独立路径数增长；D=0 删除延迟寄存器，Level 1 删除 B 延迟，Level 0 删除全部 B 逻辑。
静态 mask 可裁剪对应比较位；P=1 以每路 W 个寄存位换取 XOR/mask 与归约/状态路径分隔。
Sticky 向量额外占用最多 W 个寄存位和反馈 OR 逻辑。

综合可能合并等价 A/B 节点，因此需要禁合并约束与映射后结构检查。
若单文件形式无法可靠保留冗余边界，应如实记录限制；RTL 双份状态本身不能证明物理独立性。
公共时钟/复位、输入、最终汇总与状态输出仍需要系统安全分析和物理布局签核。

## 综合实测后的边界修订

首轮 DC 保留了 166 个寄存器，但将 generate 域中的组合节点展平为匿名单元，
不足以约束两路独立掩码/使能锥。为满足 LCL-CMP-004，保留单 RTL 文件，
加入同文件私有 `lockstep_comparator_logic_path` 子模块作为 A/B 综合边界。
顶层端口、时序和参数不变，不增加独立 CBB 依赖；综合关闭跨边界优化和自动展平，
并关闭寄存器合并。此修订触发完整功能回归与重新综合。
