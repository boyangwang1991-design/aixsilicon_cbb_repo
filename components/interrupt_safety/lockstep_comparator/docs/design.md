# 架构设计

采用单个手写参数化 SystemVerilog 文件、一个公共顶层和同文件私有通道模块，无 package 或运行时子依赖。
SV 归约运算足以描述比较器，无需 Python 生成 RTL。

每路独立 generate 域保存延迟、启动计数、有效掩码、差异向量、可选结果寄存和归约输出。
Level 0 仅有 A；Level 1 仅共享 A 的输入延迟与启动状态；Level 2 的 B 拥有独立存储。
公共 `alignment_valid_o` 只作观测输出，不反馈为可以同时关闭两路的内部共享比较使能。

差异向量按位 OR 形成诊断；两路归约结果 OR 形成被保护逻辑差异，XOR 形成内部故障。
Sticky 分类别记录、置位优先。本模块无功能数据输出，不进入被保护逻辑主路径。

每套独立延迟需要 D×W 存储位；非零启动窗口需要 ceil(log2(D+G+1)) 计数位；
每路输出流水需要 P×W 位，最终 sticky 需要 W+2 位。D=G=0 无延迟和启动状态。
单时钟域、异步低有效本地复位，释放同步由集成端负责。
