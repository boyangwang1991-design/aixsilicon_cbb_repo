# AI PPA Advisor

解释热点、生成方案并驱动闭环（架构文档 10.1 节，P2）。

## 规划功能

- 解释 RTL Pattern Scanner 识别出的热点与瓶颈
- 结合 PPA 数据与 Recipe 推荐 CBB、实现与参数
- 生成可复核的选型报告（依据、权衡、预期收益、风险）

## 职责边界（10.3 节）

AI 适合：需求转约束、热点解释、候选搜索、Recipe 匹配、参数建议、报告生成。
确定性工具负责：代码生成、Schema 校验、综合、STA、功耗、形式验证和 Gate 判定。
**最终选择必须由工具证据闭环。**
